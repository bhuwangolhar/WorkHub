# WorkHub

A multi-tenant office management SaaS. Companies can manage departments, employees, roles, leave requests, and announcements, with each company's data kept fully isolated from the others.

> **Status:** Work in progress.

## Features (planned)

- Organization signup and invite-based onboarding
- Departments and employees (archive instead of delete)
- Role-based access: Owner, Admin, Manager, Employee
- Leave requests with manager approval and leave balances
- Announcements (company-wide or per department)
- Audit log of important changes
- Background jobs for leave balances and monthly reports

## Tech Stack

- **Backend:** Node.js, Express, TypeScript
- **Frontend:** React
- **Database:** PostgreSQL (Neon), Drizzle ORM
- **Jobs:** BullMQ + Redis
- **Tooling:** Docker, GitHub Actions
